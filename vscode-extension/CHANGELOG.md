# Change Log

All notable changes to the AvangCLI VSCode Extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2024-XX-XX

### Added
- Initial release of AvangCLI VSCode Extension
- Project initialization command with full configuration options
- Module generation with state management support
- Configuration regeneration capability
- TypeScript client generation from OpenAPI specs
- Context menu integration in explorer and file views
- Settings configuration for default options
- Terminal integration for command execution
- Installation guidance and error handling
